# Sweets platform: notes for AI assistants

Read `docs/ARCHITECTURE.md` first. Key rules:

- pnpm + Turborepo monorepo. Shared packages (`@sweets/types`, `@sweets/api-client`) compile to
  `dist/`; run `pnpm build` (or `pnpm dev`) so apps see changes. The Prisma client is generated by the turbo `generate` task.
- Prisma 7 with the `prisma-client` generator (CJS output at `apps/api/src/generated/prisma`,
  gitignored) and the `@prisma/adapter-pg` driver adapter. DB URL comes from `prisma.config.ts`.
- Prisma enums must match `packages/types/src/enums.ts`.
- Update schemas in `@sweets/types` must be built from base shapes **without** `.default()`, so
  `.partial()` never resets omitted fields on PATCH.
- Use `dateTimeSchema` rather than `z.coerce.date()` (Swagger can't render Date).
- All order status changes go through `OrdersService.transition()`. All stock changes write a
  `StockMovement`.
- Verify with `pnpm typecheck` and `pnpm build`.
- Storefront: never export non-component values from a `'use client'` file for server components
  to import (they become client references). Put shared constants in `lib/`.
- Storefront copy and business details are placeholders in `lib/site.ts` and `content/`.
